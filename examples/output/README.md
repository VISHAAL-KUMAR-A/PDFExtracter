# Output Examples

This directory contains example Excel files generated by the PDF extraction tool.

## File Naming Convention

Generated files follow this pattern:
- `extracted_data_<session_id>.xlsx`

## Excel Structure

### Template 1 Output
The Excel file will contain the following tabs:
1. Fund Information
2. Fund Manager
3. Financial Position
4. LP Investors
5. Fund Companies
6. Company Valuations
7. Company Financials
8. Investment History

### Template 2 Output
The Excel file will contain the following tabs:
1. Executive Summary
2. Schedule of Investments
3. Operations Statement
4. Cashflow Statement
5. PCAP Statement
6. Portfolio Companies
7. Portfolio Financials
8. Footnotes

## Notes

- Each tab is formatted with headers and proper styling
- Numerical values are preserved as numbers for calculations
- Empty fields are shown as blank cells
- Data is organized in tables for easy analysis
