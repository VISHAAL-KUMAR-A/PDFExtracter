# Sample PDF Files

This directory should contain sample PDF files for testing the extraction tool.

## Instructions

Place your PDF files here for testing. The tool supports:
- Single PDF extraction
- Multiple PDF extraction (batch processing)

## Recommended Test Files

1. **Private Equity Fund Reports** - Quarterly or annual fund performance reports
2. **Investment Statements** - Portfolio company investment details
3. **Financial Statements** - Company financial data and valuations

## Notes

- All PDFs should be text-based (not scanned images) for best extraction results
- Files should ideally contain structured financial data
- The AI model will attempt to extract data according to the selected template
